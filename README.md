# 🚗 8891 中古車智慧管理與估價系統

一個基於 Python Tkinter 與 Pandas 開發的桌面端中古車資訊管理與智慧估價應用程式。本系統整合了近 4 萬筆台灣 8891 中古車市場實時交易數據，提供車輛檢索、多維度篩選排序、市場行情分析以及基於折舊演算法的 AI 智慧二手車價估算功能。

## 🌟 系統功能特色

### 1. 📂 車庫資料智慧讀取與清單管理
* **多來源容錯讀取**：自動優先搜尋本地 SQLite 資料庫（`auto8891.db`、`auto_car_8891.db`、`cars.db`），若無則自動降級讀取 CSV 備援檔案（`8891_cars.csv`、`cars.csv`）。
* **欄位模糊對應**：彈性相容不同命名風格的資料欄位（如「縣市地區」/「city」、「售價」/「price」），提升資料導入相容性。
* **多維度篩選**：
  * **縣市分類**：依據資料庫實際縣市動態建立選單，支援依地區快速篩選。
  * **關鍵字搜尋**：支援車款標題之子字串模糊即時檢索（不分大小寫）。
* **雙向智慧數值排序**：
  * 支援點擊表頭對「**售價**」、「**年份**」、「**里程**」進行排序。
  * 內建單位正規化解析器，能正確解析並排序帶有「萬」、「公里」等中文單位的字串（例如：「26.8萬」大於「9.5萬」）。
  * 點擊表頭可於 **從小到大 (🔼)** 與 **由大到小 (🔽)** 之間快速切換。

### 2. 💰 AI 智慧車價預測估價
* **車輛條件輸入**：支援選擇市售熱門車系（Toyota RAV4、Honda CR-V、Altis、BMW 3 系列、賓士 A-Class 等）、出廠年份（2010 ~ 2026）與累計里程。
* **市場估價模型**：
  * 依品牌基礎價值、車齡年折舊率與里程消耗折損進行動態精算。
  * 設定車輛最低殘值保護機制。
* **專家交易建議**：輸出市場行情預估區間（±5%），並同時針對買方合理的議價範圍與賣方收購行情提供參考。

## 🖥 操作指南

### 1. 車庫資料與清單管理
1. **瀏覽車輛**：啟動後會自動載入資料庫車輛清單，可透過右側垂直捲軸滾動瀏覽。
2. **地區篩選**：點擊「縣市」下拉選單，選擇特定縣市（例如「新北市」），清單即會即時更新。
3. **車款搜尋**：在「關鍵字」輸入框輸入車名或型號（例如 `CR-V` 或 `Altis`），點擊「搜尋」按鈕進行過濾。
4. **智慧排序**：點擊表格標題列中的「**售價**」、「**年份**」或「**里程**」，清單會依實際大小排序，標題會顯示 `🔼`（升冪）或 `🔽`（降冪）標記。
5. **重設資料**：點擊「重新載入資料庫」可清除當前篩選並重整清單。

### 2. AI 智慧車價預測估價
1. 切換至分頁「**💰 AI 智慧車價預測估價**」。
2. 於表單中設定估價條件：
   * **熱門車系**：挑選或自行輸入車款名稱。
   * **出廠年份**：設定車輛出廠年（2010 ~ 2026）。
   * **行駛里程**：輸入累計里程（單位：公里，需為純數字）。
3. 點擊「**✨ 開始計算預估車價**」。
4. 於下方分析結果面板即可檢視：
   * 預估市場行情區間（新台幣元）。
   * 針對買方與賣方的專家行情建議。

## 💡 核心演算法與技術亮點

### 1. 帶單位中文數字正規化解析器 (`parse_numeric`)
一般字串排序會導致「9.5萬」排在「26.8萬」之後（字元 '9' > '2'）。本系統實作正則與數值單位轉換邏輯：
```python
# 核心原理：透過正則萃取數值，並將「萬」單位乘以 10,000 轉換為標準 float
if "萬" in s:
    num *= 10000
```
使得售價與里程能以真實數值做精準大小比對與排序。

### 2. 二手車估價折舊演算法
系統模擬中古車市場常見之折舊曲線：
$$\text{預估售價} = \text{基礎車價} - (\text{當前年份} - \text{出廠年份}) \times 40,000 - \text{行駛里程} \times 1.5$$
* 基礎車價：日系國民車款（Toyota 等）為 70 萬，進口/高階車款設定為 95 萬。
* 最低殘值保底：設定門檻為 150,000 元。
* 行情區間帶：以基準價之 $\pm 5\%$ 建立市場成交與議價緩衝範圍。
